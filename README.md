# ⚡ OMEGA v4.0 - Hybrid Autonomous Intelligence

**Architect:** Owoicho Emmanuel | **License:** MIT

OMEGA is a 7-agent autonomous system that cleans data, validates it, analyzes it, auto-selects the best ML model, and generates a decision report.

## Agents
- **MATRIX** - Statistical Analysis
- **PHOENIX** - Auto-Clean
- **TITAN** - Auto-Model Selection (Linear vs Random Forest)
- **NEXUS** - Decision Engine
- **SYNAPSE** - Report Assembly
- **SENTINEL** - Validation
- **ORACLE** - Intelligence Report

```bash
pip install -r requirements.txt
python omega_v4.py
